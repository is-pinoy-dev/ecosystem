## How to read a CI failure

When CI fails on your PR, the `github-actions` bot posts a comment titled **❌ Subdomain Validation Failed** containing the exact validation output. On each new push it edits that comment rather than adding another, so there is only ever one to read.

The most common causes are:

1. **Schema validation failed** — your JSON file has a formatting or value error
2. **Filename mismatch** — the `subdomain` field and the filename disagree
3. **Reserved or duplicate subdomain** — the name is taken or reserved for platform use

See [CI Failures](/guides/troubleshooting/ci-failures) for how to read the comment, and [Common Errors](/guides/troubleshooting/common-errors) for each message.
